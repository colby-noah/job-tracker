# job-tracker

A job application tracking web app (in progress). Frontend: React + TypeScript. Backend: Express + PostgreSQL (planned).

## Tech stack

* React
* TypeScript
* Vite
* ESLint + Prettier
* GitHub Actions

## Getting started

### Prerequisites

* Node 24

### Commands

Install & run

```sh
cd web
npm install
npm run dev
```

Format & lint

```sh
cd web
npm run format
npm run lint
```
